# Hero-Bilder

Ein Bild pro Seite. Datei ersetzen (gleicher Name, .jpg/.png/.webp), dann `python3 build.py` – die Seite nimmt das neue Bild.

| Datei | Seite |
|---|---|
| 01-startseite | Startseite (großes Bild rechts im Hero) |
| 02-reparatur | Endoskop-Reparatur |
| 03-leihgeraete | Leihgeräte |
| 04-ankauf | Ankauf |
| 05-endoskopie-anlagen | Endoskopie-Anlagen |
| 06-ueber-uns | Über uns |
| 07-kontakt | Kontakt |

Seiten ohne Hero-Bild: Kostenrechner, Gebrauchte Endoskope, Produktseiten, Formulare, Rechtliches.
